# Dynamic Pricing System – Data Analytics & Business Intelligence Project

The **Dynamic Pricing System** is a web-based application developed using **Python** and **Streamlit** that simulates real-time pricing strategies used in modern businesses. The system automatically adjusts product prices based on demand, stock availability, and market conditions while providing interactive analytics and business insights through a modern dashboard.

---

## Use Cases

### Dynamic Pricing

- Automatically calculates product prices based on:
  - Demand
  - Stock Availability
  - Market Conditions
- Simulates real-time price fluctuations.
- Helps businesses maximize profit while maintaining competitive pricing.

### Business Analytics

The dashboard provides powerful analytical insights including:

- Average Base Price
- Average Dynamic Price
- Profit Analysis
- Best Performing Product
- Pricing Recommendations
- Complete Dataset Analysis

### Interactive Visualizations

The application includes multiple charts to help understand pricing trends:

- Bar Chart – Top Products by Dynamic Price
- Pie Chart – Seasonal Product Distribution
- Histogram – Dynamic Price Distribution
- Scatter Plot – Demand vs Dynamic Price
- Trend Line – Price Trend Analysis
- Correlation Heatmap – Relationship Between Variables

### Recommendation System

Based on product demand, the system intelligently recommends whether to:

- Increase Price
- Decrease Price
- Keep Price Stable

This helps businesses make data-driven pricing decisions.

### Best Product Identification

The system automatically identifies the product with the highest dynamic price, helping businesses quickly recognize their best-performing product.

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Dynamic-Pricing-System.git
```

Navigate to the project directory:

```bash
cd Dynamic-Pricing-System
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
